### Quick Commands for your WSL2/Kali terminal:

1.  **To create the file and add these libraries:**
    ```bash
    nano requirements.txt
    ```
    *(Paste the list above, then press `Ctrl+O`, `Enter`, and `Ctrl+X` to save)*

2.  **To install everything inside your virtual environment:**
    ```bash
    pip install -r requirements.txt
    ```
